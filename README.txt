StoreMaster V8.3 — Smart Orders Cache

المحتويات:
- code-23.gs: Google Sheets API + أرشيف 30/90 + UpdatedAt + syncOrders.
- adm-23.html: لوحة الإدارة + IndexedDB Smart Cache.
- storemaster-worker-23.js: Worker مع تمرير syncOrders.

النظام:
1. Google Sheets هو المصدر الرئيسي للبيانات.
2. IndexedDB ذاكرة محلية لكل جهاز/متصفح فقط.
3. عند فتح الطلبات تظهر البيانات المحلية أولاً، ثم تتم مزامنة الطلبات الجديدة/المعدلة في الخلفية.
4. كل صفحة يتم تحميلها من السيرفر تُحفظ محلياً، لذلك تصبح العودة إليها سريعة جداً.
5. فتح الطلب يستخدم الذاكرة المحلية أولاً مع تحقق من السيرفر وتحديث الكاش.
6. تغيير الحالة يحدّث UpdatedAt ويُحفظ فوراً في الكاش.
7. الطلبات النشطة 30 يوماً، ثم Archive_Commandes حتى 90 يوماً، ثم حذف نهائي.
8. localStorage يبقى فقط للإعدادات/الإشعارات؛ لا تُحفظ الطلبات الفعلية فيه.

مهم: بعد استبدال code.gs شغّل setupArchiveSystem مرة واحدة إذا لم يكن Trigger الأرشيف قد أُنشئ سابقاً. لا تحتاج أي قاعدة بيانات مدفوعة.
